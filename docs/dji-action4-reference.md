# DJI Osmo Action 4 · 3D 建模参考资料

> 用途：`dji-action4-3d` Three.js 拆解可视化项目的建模 / 参数面板数据源。
> 调研方式：直连 DJI 官方规格页 + 官方《用户手册 v1.2》PDF（含矢量部件图）+ DJI 官方产品图。
> 调研时间：2026-10-27。**本环境 web_search 不可用（无 API key），未做第三方评测横向检索，也没有找到可信的公开完整拆解资料** —— 因此内部结构部分大量标注「未证实」。

## 0. 置信度图例（全文通用）

| 标记 | 含义 | 误差量级 |
|---|---|---|
| **官方** | DJI 规格页 / 用户手册原文 | 0 |
| **官方图·换算** | 由官方数据（英寸/ppi/像素）数学换算 | <0.5 mm |
| **估算** | 由官方部件图、产品照片按比例推断 | ±1.5 ~ 3 mm |
| **粗估** | 单一照片/示意图推断，方向可信、数值误差大 | ±3 ~ 6 mm |
| **未证实** | 无可靠公开资料，含推测 | 不可用于精确建模 |

**坐标约定（第 8 节起全部使用）**
- 原点 = 机身几何中心；单位 mm。
- **+X = 观察者面向镜头面时的右手方向（镜头所在侧）**；+Y = 上；**+Z = 镜头面朝外（前）**。
- 机身包围盒：X ∈ [-35.25, +35.25]，Y ∈ [-22.1, +22.1]，Z ∈ [-16.4, +16.4]。
- ⚠️ **重要纠偏**：镜头位于正面**观察者右手侧**（+X），不是偏左；前屏在观察者左手侧（-X）。见 §2.1 依据。

### 2.1 左/右方向判定（已交叉验证，置信度高）

依据 A：官方手册 p5「认识 Osmo Action 4」部件图（三视角等轴测图）。

官方部件表（手册 p5，件号用于下文）：

## 9. Three.js 实现建议（非官方，工程实践）

1. **单位/缩放**：模型按 mm 建模，整体 `group.scale.setScalar(0.02)` → 宽约 1.41 单位，默认相机距离 4~5、fov 35° 即可；或直接 mm 场景 + 相机距离 ~150。
2. **外壳**：`RoundedBoxGeometry`（three/examples）做机身更省面；正面/背面平面用独立薄板更利于贴 logo 贴图。倒角半径见 §8.1。
3. **滚花镜头环**：不要用几何齿（面数爆炸），用 `CanvasTexture` 画径向齿纹作为 normal/roughness map + 圆柱环；如需近景齿感，用 48 个实例化小盒（InstancedMesh）。
4. **屏幕**：黑玻璃用 `MeshPhysicalMaterial`（roughness 0.08、metalness 0、clearcoat 1、envMap）；显示内容用 `MeshBasicMaterial + emissiveMap`（自发光贴图），贴图区与黑边分层，避免 z-fighting（显示面比玻璃面高 0.15 mm）。
5. **孔洞/小件**：麦克风孔、扬声器孔、指示灯用贴图或 Φ1~3 的深色圆片 + 轻微凹陷表示；状态灯给弱自发光。
6. **接缝**：用 0.15 mm 宽的深色细线/凹槽表现前后壳分模线与屏幕边缝，比真实建模更划算。
7. **爆炸方向建议**：后屏/后壳沿 -Z 位移；镜头环沿 +Z；前屏沿 +Z；电池沿 -X 抽出；底部快拆板沿 -Y；主板（示意）沿 +Z 或 -Z 分层。
8. **颜色建议（照片取样，非官方色值）**：机身 0x1f1f22 / 0x2a2a2e；镜头环 0x3a3a3e；红环 0xd3262e；屏幕黑 0x0a0a0c；屏幕内容按 UI 取色。
